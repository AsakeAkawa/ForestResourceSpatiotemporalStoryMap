# ForestResourceSpatiotemporalStoryMap
本项目是一个基于WebGIS技术的交互式科学可视化项目，以在线叙事地图的形式，生动、系统地呈现中国过去40年间森林生态系统的时空演变历程。This project is an interactive scientific visualization project based on WebGIS technology. It presents the spatiotemporal evolution of China’s forest ecosystems over the past 40 years in a vivid and systematic way, in the form of an online narrative map.
